# Edge AI-Based Automotive Rodent Detection and Prevention System

Built a real-time edge AI system for rodent detection in automotive engine compartments using YOLOv8 on
embedded hardware (Raspberry Pi), achieving great precision and mAP; developed an end-to-end pipeline with
on-device inference, automated GPIO-based deterrence, and real-time email alerts, along with a scalable
monitoring dashboard for event tracking, analytics, and system performance evaluation.

## Tech Stack: python,YOLOv8,openCV,NumPy,Raspberry Pi5,GPIO.
